# CS Serviços

Site institucional desenvolvido para a CS Serviços, empresa voltada à orientação em crédito consignado, auxílio-acidente e atendimento personalizado.

## 🌐 Site

[Visitar o site](https://devalexoliveirasistems.github.io/cs-servicos/)

## 📌 Sobre o projeto

O projeto foi desenvolvido com foco em:

- apresentação profissional da empresa;
- navegação simples e intuitiva;
- experiência responsiva em desktop e dispositivos móveis;
- integração com WhatsApp;
- presença digital e SEO básico;
- estrutura preparada para publicação na web.

## 🚀 Funcionalidades

- Menu responsivo para dispositivos móveis;
- Navegação por seções;
- Botões de contato;
- Integração com WhatsApp;
- Link para Instagram;
- Design responsivo;
- Favicon;
- SEO básico;
- Dados estruturados com Schema.org;
- Open Graph para compartilhamento.
